# Monitoring data and model drift

Five scripts track a baseline random forest through changes in the data. They evaluate accuracy, retrain models and compare tuned classifiers and an ensemble. Model and scaler versions carry results between stages.

## Run locally

```sh
python -m pip install -r requirements.txt
python projeto7-parte1.py
python projeto7-parte2.py
python projeto7-parte3.py
python projeto7-parte4.py
python projeto7-parte5.py
```
